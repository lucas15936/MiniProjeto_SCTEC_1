# Serão enviados dois arquivos que podem ser executados dependendo da escolha do usuário, um arquivo .py e um arquivo .ipynb. 

## O arquivo .py necessita de instalação das bibliotecas utilizadas (na IDE que for ser utilizado ou no ambiente virtual que for ser utilizado ou na máquina em que o python está instalado), como a pandas, por exemplo. E instalação de ferramentas como 'display' ou alteração dessas ferramentas. O local de destino do arquivo .csv está configurado corretamente pronto para uso, não devendo ter problemas nesse ponto.

## O arquivo .ipynb necessita ser colocado no ambiente do Google Colab em conjunto com o arquivo 'Base_Varejo.csv' em destinos escolhidos apropriadamente e deve ser feita a alteração da linha de código que define caminho de destino do arquivo .csv na primeira célula do código.

## O arquivo 'README.md' possui informações a respeito do projeto. 

## Por conta do Github não aceitar arquivos grandes, os arquivos .csv foram compactados antes do envio. Deve-se descompactá-los e colocá-los na mesma pasta do código .py se for utilizá-lo diretamente.
